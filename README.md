# DevKit — Developer Tools

**Small tools. Faster workflows.**

DevKit is a modern, browser-based collection of essential developer utilities built to simplify everyday development tasks. It brings formatting, encoding, data generation, text transformation, and conversion tools together in one responsive interface.

🌐 **Live Demo:** https://shadhinsahriar.github.io/DevKit/

## ✨ Features

### 🧩 JSON Formatter & Validator
- Format and beautify JSON with configurable indentation.
- Minify JSON into a compact format.
- Validate JSON syntax.
- Load sample JSON for testing.
- Copy formatted output to the clipboard.
- Download JSON files.

### 🔐 Base64 Encoder & Decoder
- Encode text into Base64.
- Decode Base64 into readable text.
- Support UTF-8 text, including multilingual content.
- Swap input and output.
- Copy converted results.

### 🔗 URL Encoder, Decoder & Parser
- Encode URL components.
- Decode percent-encoded strings.
- Parse absolute URLs into their components.
- Inspect URL structure.
- Copy parsed or transformed output.

### 🆔 UUID Generator
- Generate UUID version 4 identifiers.
- Generate multiple identifiers at once.
- Choose the quantity from 1 to 100.
- Select uppercase formatting.
- Copy generated UUIDs.

### 🎨 Color & Gradient Studio
- Inspect and select colors.
- Work with HEX, RGB, and HSL color formats.
- Create custom linear gradients.
- Adjust gradient colors and angles.
- Preview color combinations.
- Copy generated CSS.

### 📝 Text Tools & Analyzer
- Count characters, words, lines, and paragraphs.
- Convert text to uppercase and lowercase.
- Convert text to title case.
- Trim unnecessary whitespace.
- Remove duplicate lines.
- Sort lines alphabetically.
- Reverse text.
- Copy or reuse transformed output.

### ⏱️ Unix Timestamp Converter
- Convert Unix timestamps into readable dates.
- Convert dates into Unix timestamps.
- Display UTC and local time.
- Generate ISO 8601 date strings.
- Convert between Unix seconds and milliseconds.
- Set the current time for quick conversion.

### 🔎 Developer-Friendly Interface
- Unified dashboard and tool navigation.
- Search interface for finding developer utilities.
- Responsive application layout.
- Consistent input and output panels.
- Clear action buttons and practical workflows.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and responsive layout |
| Vanilla JavaScript | Tool functionality and interactions |
| Browser APIs | Encoding, clipboard, UUIDs, dates, and local processing |
| GitHub Pages | Static website hosting |

DevKit is designed as a single-file web application without a required backend, package manager, or build process.

Try DevKit directly in your browser:

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/shadhinsahriar/DevKit.git
```

Enter the project directory:

```bash
cd DevKit
```

Open `index.html` in your browser.

If browser restrictions affect features such as clipboard access, use a local development server or the hosted HTTPS version.

## 🌍 Deployment with GitHub Pages

DevKit is hosted using GitHub Pages.

To deploy your own changes:

1. Push your updated `index.html` to the `main` branch.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and the `/ (root)` directory.
6. Save your settings and wait for deployment.

Your website will be available at:

https://shadhinsahriar.github.io/DevKit/

For more information, see the [GitHub Pages documentation](https://docs.github.com/en/pages).

## 🔒 Privacy & Browser Processing

DevKit is designed to perform its core operations directly in the browser without requiring a backend.

- No account or API key is required.
- Core transformations can be performed locally.
- Clipboard access depends on browser permissions.
- Browser storage and permissions may affect certain features.

Avoid entering sensitive information into any web application unless you understand its implementation and security limitations.
